# Лабораторная работа №1 — Вариант 20

Родительский процесс создает два дочерних процесса. Родительский и дочерний процесс представлены разными программами.
Родительский процесс принимает от пользователя строки произвольной длины и пересылает их в `pipe1` или в `pipe2`
в зависимости от длины строки: строки длины больше 10 символов отправляются в `pipe2`, иначе в `pipe1`.
Дочерние процессы инвертируют строки. Процесс `child1` и `child2` производят работу над строками.
Процессы пишут результаты своей работы в стандартный вывод.

## Сборка
```sh
    gcc -Wall -Wextra -o parent parent.c
    gcc -Wall -Wextra -o children children.c
```

## Запуск
Запустите, введите первой строкой имя файла, которое будет использовано для открытия файла с таким именем на запись для `child1`.
Аналогично для второй строки и процесса `child2`. Вводите строки пока не введёте `Ctrl-D` или `Enter` на пустой строке для завершения.

```sh
    ./parent
```
