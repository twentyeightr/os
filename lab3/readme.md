# Лабораторная работа №3 — Вариант 20

Родительский процесс создает два дочерних процесса. Родительский и дочерний процессы представлены разными программами.
Взаимодействие между процессами происходит через именованную разделяемую память (shared memory). 
Так как разделяемая память не блокирует процессы при чтении/записи, для синхронизации используются именованные семафоры.
Родительский процесс принимает от пользователя строки произвольной длины. Строки длиной больше 10 символов отправляются для `child2`, иначе для `child1`.
Дочерние процессы инвертируют строки и пишут результаты своей работы в стандартный вывод.

## Сборка
```sh
    cc -O2 -o parent parent.c -lrt
    cc -O2 -o children children.c -lrt
```

## Запуск
Запустите `parent`. Вводите строки с клавиатуры. 
Для завершения нажмите `Ctrl-D` или `Enter` на пустой строке.

```sh
    ./parent
```
